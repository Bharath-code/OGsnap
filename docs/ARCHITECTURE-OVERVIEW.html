Tech Stack

Frontend: Next.js 15
Landing page + Dashboard with App Router
Backend: Convex
API + Database + Actions (serverless)
Renderer: Playwright
HTML → PNG conversion
Storage: Cloudflare R2
Free egress, S3-compatible
Auth: Clerk
User authentication
Billing: DodoPayments
India-friendly subscriptions
Brand: Firecrawl
URL → brand data extraction
CDN: Cloudflare
Image delivery & caching

Brand Extraction Process:

  1. Fetch HTML from user's URL via Firecrawl
  2. Extract og:image or favicon for logo
  3. Extract theme colors from meta theme-color or CSS
  4. Extract font-family from stylesheet
  5. Save to brandKits table
  6. Generate 5 sample OG images with different titles

8. Quick Start

# 1. Install dependencies
pnpm install

# 2. Set up environment variables
cp apps/web/.env.local.example apps/web/.env.local
# Fill in your API keys

# 3. Start development
pnpm dev:convex     # Terminal 1 - Backend
pnpm dev:renderer   # Terminal 2 - Renderer
pnpm dev:web       # Terminal 3 - Frontend

# 4. Open browser
open http://localhost:3000
